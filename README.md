# پروژینو (Projino)

مدیریت پروژه و وظایف شخصی، فقط برای ویندوز، کاملاً فارسی و راست‌به‌چپ. داده‌ها فقط روی همین رایانه ذخیره می‌شوند.

## ساخت فایل نصبی (.exe)

### روش ۱: با GitHub (بدون نصب چیزی روی رایانه)
1. یک مخزن (Repository) تازه در GitHub بساز و همهٔ فایل‌های این پوشه را در شاخهٔ `main` بفرست.
2. در تب **Actions** گردش‌کار `build-windows` خودکار اجرا می‌شود (یا دستی: Run workflow).
3. بعد از حدود ۵ تا ۱۰ دقیقه، در پایین صفحهٔ همان اجرا، بستهٔ **Projino-windows** را دانلود کن. داخلش فایل نصبی `Projino_1.0.0_x64-setup.exe` و نسخهٔ `projino.exe` است.

### روش ۲: روی رایانهٔ ویندوزی خودت
نیازمندی‌ها: Node.js 20 به بالا، Rust (از rustup.rs) و Visual Studio Build Tools با گزینهٔ «Desktop development with C++». ویندوز ۱۰ یا ۱۱ با WebView2.

    npm install
    npm run tauri dev      # اجرای آزمایشی
    npm run tauri build    # ساخت نصب‌کننده

خروجی: `src-tauri/target/release/bundle/nsis/`

## اجرای فقط رابط در مرورگر (برای توسعه)
    npm install
    npm run dev
در این حالت داده‌ها در localStorage مرورگر نگه داشته می‌شوند. در برنامهٔ واقعی در SQLite ذخیره می‌شوند.
